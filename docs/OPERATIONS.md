# 运行安全与后续真实模型验收

本阶段按用户选择只做离线改进，未发送真实模型请求。模型 ID、Endpoint、能力声明和价格必须由部署方确认；ChatGPT 订阅不是 API 凭证。没有新增运行依赖或自动清理调度。P7 已增加维护窗口主密钥 CLI 和显式确认的数据保留 CLI，见 [P7 运行维护](P7_RUNTIME.md)。

## 凭证和交付边界

沿用 AES-256-GCM、随机 nonce、`v1:tenant_uuid:credential_ref` AAD，ref 不可重命名。请求前在当前企业解析启用凭证，模型 I/O 后及结果交付事务再次检查配置版本、凭证启用/存在性和密文变更标记。交付事务锁配置及凭证行，更新/删除在提交点排序；在途轮换或删除使新结果失败且不落助手正文，但保留真实可得用量。内部密文 fingerprint 不通过 API 返回。

已提交历史不会因凭证轮换被删除。删除凭证后新请求安全失败，没有共享密钥或备用凭证旁路。已经发送给远端的请求无法由本地删除保证取消，仍可能收费；不承诺远端执行与数据库授权状态的分布式原子性。

模型错误只返回分类，不回传供应商原始错误正文、密钥、堆栈。仅明确模型不可用或不支持工具时才尝试已配置备用；429 的额度不足与普通限速区分。兼容性测试未证明任何具体厂商/模型能力。

## 主密钥轮换

P7 已实现版本化密文封装、新旧密钥兼容读取、单企业原子重加密、预览/检查/执行/恢复 CLI。必须停止旧配置进程并排空在途调用，保留全部旧密钥和可恢复备份；不提供在线热配置分发。具体命令、故障恢复边界见 [P7 运行维护](P7_RUNTIME.md)。普通企业 API Key 轮换继续使用原 HTTP 接口，与主密钥轮换不同。

## 用量与运行限制

部署变量详见 `.env.example`。企业、当前用户、Agent 三个范围都必须准入；跨 HTTP worker 通过 PostgreSQL 事务 advisory lock 串行统计/预留，不依赖进程内计数器。读取范围限当日、最近一分钟与仍活跃记录。GET `/api/v1/usage-limits` 返回部署限额、当前企业/用户用量；Agent 按实际调用配置单独准入。

- 模型最坏预留：RAG/连接测试一轮、Agent 最多五轮，每轮考虑主/备用及最多两次传输；按配置输入/输出上限计算。连接测试按 32 输出上限预留及发送。请求可能因保守预留提前拒绝。
- 完整且单次传输的步骤按返回 Token 结算；超时、进程丢失、重试未给全量账单时保留原预留到下一 UTC 日窗口，不将 null 当 0。部分已知 Token 可展示，不能解释为精确总账。没有供应商价格计费或金额硬上限。
- 每个网络请求（包括幂等重放）仍计入 HTTP 入口反滥用计数；业务幂等重放不会重复模型准入或工具执行，两者不是同一计数。模型和工具循环/时间预算保留 P3 边界。旧记录迁移保守回填，以免把未知费用当作免费。
- 活跃调用到期后查询/后续调用归类结果未知，不自动重发。通用 HTTP 入口限流已实现但默认关闭；生产负载验证和分布式配额账单核对仍需上线前单独验收。UTC 日切换统计窗口不删除记录。

## 数据保留和删除规则

当前安全限制：会话/访客保留计划如选中任何会话，预览会返回 `executable=false`、`blocked_reason=user_scoped_cascade_review_required`。个人记忆和已读游标受用户级 FORCE RLS 保护，租户运维上下文无法完整计数其级联影响，因此暂时拒绝该类清理，不绕过 RLS，也不将不可见行计作零。审计和独立调用记录可在关闭会话/访客期限与文档清理选项后单独预览；执行仍须目标环境授权。文档清理另因历史 JSON 引用未完整枚举而 BLOCKED，返回 `knowledge_reference_review_required`；未知数量为 `null`，不将未知影响作为可确认删除。恢复会话清理前需独立审查用户级依赖、数量上限、锁和确认摘要，见[深度审查记录](DEEP_AUDIT_REPORT.md)。

预览现包含对象 ID、内容/版本摘要、删除/脱敏/保留/阻断范围；不可见或超出总计 10000 行上限的依赖计数为 `null`（UNKNOWN），不能确认执行。可执行的审计/独立调用批次使用 v3 确认摘要绑定对象和依赖指纹；内容或集合变化须重新预览，执行仅处理同一锁定批次。文档/知识库物理删除及既有 deleting 文档的 CLI 清理均阻断：保留现状，不再 unlink 或删除历史版本。已有墓碑只作为待处理证据，不承诺文件完整或跨介质原子性。幂等回执由审计保留，随审计期限可能清除，不是永久删除账本。

| 数据 | 当前规则 |
| --- | --- |
| 会话、消息、模型步骤、工具执行 | 默认保留；CLI 支持预览，选中会话时暂时阻断执行，原因见上文。普通成员没有批量删除接口，默认无定时任务。 |
| 知识库、文档、分块及上传文件 | 企业管理员可用 DELETE + `preview=true` 查看已知范围/UNKNOWN；实际 DELETE 返回 409，未改变状态或删除数据/文件。历史引用完整性未证明，禁止通过存储目录绕行。 |
| 分块人工修订/删除/恢复 | 每次生成新 ID 和 revision，原正文保留；只检索当前代、当前非删除版本。重新处理保留旧代供管理员只读查阅；整文档物理删除当前 BLOCKED，逻辑删除不等于隐私擦除。 |
| 引用过知识的历史消息/调用 | 保留已发生的摘录；后续模型上下文/重放验证当前有效来源。知识删除不等同全链路隐私擦除。 |
| 凭证 | 管理员显式删除，后续解析失败；数据库备份和已发送远端请求另有生命周期。 |
| 审计及用量预留 | 默认保留；不因业务失败或日切而删除。后续策略须保护审计完整性与幂等关联。 |
| 备份 | P6 仅创建新隔离演练副本，已验证恢复；未改动已有备份。生产期限与恢复由运营方单独批准。 |
| 公开入口、访客会话 | 发布可下线/不可恢复撤销；访客令牌 12 小时有效、结束后失效。过期不删除历史、用量、审计与幂等记录。 |

生产前必须确定期限、访问权限、法定保留、导出/擦除范围和恢复后的删除重放流程。不可将默认无限保留当成已完成的生产合规策略。

## 真实客服验收步骤（待授权）

1. 用户先确认 Provider、具体模型 ID、Endpoint 和首次测试总预算（币种/上限），再安全配置主密钥、主机白名单和企业凭证。密钥不粘贴聊天、不进入报告；用已有 `/model-credentials`、`/agent-configs` API 管理。先核对厂商的 JSON 输出、工具、Token 参数和温度支持声明。
2. 首次仅显式 POST `/api/v1/agent-configs/{id}/test-connection`（最多 32 输出 Token，仍可能收费），检查分类和用量。它只检查连接/解析，不证明工具调用能力。
3. 专用评测数据和执行器已移除。只有取得明确运行授权后，才可在批准的环境人工确认实际客服行为；不能依据本节自动执行 API 或创建验证数据。已授权只读工具仍由静态注册表执行，未授权/写工具由服务器拒绝。
4. 每例记录实际 Provider/模型、输入输出 Token（未知保留 null）、墙钟耗时、步骤/工具次数、来源、错误分类和人工答案正确性；多轮记录中间回合，复核跨企业/会话边界。降级/超时等不可安全制造的远端故障保留受控测试证据，明确未做真实故障注入。
5. 人工核对答案是否充分、引文是否支持结论、冲突/无证据是否拒答，注入是否泄露提示/凭证或诱发未授权动作；不能把 grounded 或 HTTP 200 当正确性。路由切换须验证完整历史仍在，未知网络结果不得盲目重试。先检查用量，不自动跑无限评估或使用全额预算。

目前不保留专用评测执行器；常规质量检查只做静态分析。真实质量、一般语义冲突、任意提示注入抵御和供应商实测能力仍未验证。后续真实模型阶段须另行授权补齐这些验收；P5 仅进行产品化离线验证，当前不实现任何行业连接器。

P5 补充：同源 Cookie、访客令牌、PUBLIC_RATE_KEY、公开额度、代理限流与三部分备份关系见 README 和 DEPLOYMENT。内部是企业成员共享会话；公开是逐访客能力隔离。P7 的维护窗口轮换与保留能力取代早期仅有方案的状态，验证范围见 P7_ACCEPTANCE。

P8 提供队列、负责人及协作历史、会话级摘录摘要、UTC 有界运营指标与访客反馈；口径及安全边界见 [P8 验收](P8_ACCEPTANCE.md)。保留预览包含备注、摘要和反馈关联计数，删除会话时级联；不自动清理数据。人工回复/内部备注提交结果未知时先查询历史，不盲目重发。预检命令和健康接口见 [P8 部署](P8_DEPLOYMENT.md)。

摘要按预算选择有序的完整用户消息，不纳入助手、工具或内部备注。单条来源超出预算时返回 `summary_source_too_large`，原文和未处理边界保留，请企业管理员调整 Agent 的 `max_input_tokens`；不会截断后声称已处理。摘要的瞬时网络故障、超时、繁忙或限流可降级到预算内近期完整对话，失败调用仍计入步骤及用量；凭证、权限或配置变化不允许降级。高置信凭证模式命中的整条来源不进入摘要，排除的消息 ID 记入审计；摘要读取也过滤这些来源，但不删除原消息或已有存储，不代表完整敏感信息识别或隐私擦除。

工作台和访客页在可见且会话有效时每 5 秒最多进行一轮消息检查，失败退避至 60 秒；管理端额外检查会话处理状态。隐藏、离开或关闭后停止轮询。消息支持 `after`/`before` UUID 游标（互斥，忽略 offset），协作记录支持 `before`；游标必须属于当前企业和会话。公开消息增加稳定的 `id`，不包含管理身份。Agent 列表可用 `q` 按名称搜索，继续使用 `limit`/`offset`，包含停用项。

## P10 运行治理

当前生产准备与边界见 [P10 记录](P10_ACCEPTANCE.md)。升级到 0010 前仍须取得目标数据库授权并保留数据库、私有文档与密钥三部分备份。HTTP 准入是可配置的 PostgreSQL 共享计数，默认关闭；上线前启用并配置共享私钥、IP/上传/SSE 阈值，数据库不可用时拒绝准入。仅 `/api/v1/health/live` 豁免入口限流；`/api/v1/health/ready` 和 `/api/v1/health/setup` 计入限流，setup 保持匿名简要响应，不返回详细配置。检查 preflight 提示，不以代理或进程内计数冒充跨实例验证。没有修改生产 Provider、工具或解析的执行超时。

知识库/文档 DELETE 带 `preview=true` 仅返回不可执行预览：知识库每页 `batch_size=1..100`，披露候选文档、该页全部代次/修订数量与未知历史关联。预览不发放确认值，执行返回 409 `knowledge_reference_review_required`；对象已不存在时保留幂等 204。旧客户端的清理调用也受后端阻断。已在 deleting 状态的库/文档保持原状，不复制旧文件或直接删目录。HTTP/数据库/SSE 安全日志不包含消息正文或认证材料，数据库耗时 DEBUG 仅按需启用；外部日志采集、告警和保留仍由部署方配置。

生产网络、权限、恢复及验收状态统一记录在 [生产上线检查清单](PRODUCTION_CHECKLIST.md)；实际备份和密钥轮换步骤分别见 [部署文档](DEPLOYMENT.md) 和 [P7 运行维护](P7_RUNTIME.md)。

HTTP 请求日志耗时到响应头阶段为止，不代表 SSE 全部交付时长；读取请求体有 30 秒预算，与整个请求和 Provider/Agent 执行时间分开。生产默认单实例，多实例须共享同一私有文档文件系统、权限、数据库和入口配置，并先完成目标环境验证。

P15-C 恢复闸门、撤销重放、监控与责任分配见 [运维交接](P15_C_OPERATIONS.md)。恢复、轮换或清理均需目标环境授权；本文能力描述不代表已演练。


当前私有部署要求 Schema `0018_core_products`（0013–0018 未在本轮执行）。可选工单/记忆 Worker、S3、内网 HTTPS 模型配置及一致性备份见[部署新增能力](DEPLOYMENT.md)。站内提醒不等于外部送达；客户记忆撤回只清除引用副本，不清来源/备份。用户、会话、客户整体擦除及知识物理删除继续 BLOCKED，保留 UNKNOWN；新增附件文件、CRM/FK、客户记忆已列入会话清理未知范围。


## 专项 A 执行控制运维

金额策略默认拒绝真实模型；先核验价格硬边界并由管理员配置，不能用连接诊断绕过。RESERVED/UNKNOWN/OVERRUN 跨期保留，进程失败不会自动退款；没有供应商对账执行入口，不能凭超时手动清零账本。R3 需另一位活动管理员审批，仅原申请人执行固定数据库操作；外部副作用继续阻断。Widget 到期/启停/重新发布/轮换将撤销旧授权，网站后端签名配置必须同步更新；客户登录身份另行验证。升级闸门见[0017 部署说明](DEPLOYMENT.md#专项-a-升级闸门0017未执行)。


专项 B 的迁移/pgvector 前提、产品 Worker 启用及导出清理边界见[0018 升级闸门](DEPLOYMENT.md#专项-b-升级闸门0018未执行)。检索诊断会按真实模型配置收费；多路召回共享 Run 金额预算。索引失败须先查看错误，再显式增量重试；修改模型/重建会立即隔离旧索引版本，旧向量暂保留且不参与查询，不表示物理擦除。全文工具连接器仍使用事务内词法快照，避免在工具执行事务中增加付费 I/O。草稿只生成内部建议，无工具调用；人工发送仍走现有会话/Widget 权限门，不能代替 R3 批准或实际退款等业务执行。
