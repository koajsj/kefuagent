# 首次使用

完成[本机快速开始](QUICK_START.md)后，以新建的平台管理员登录。平台管理员不会自动获得企业权限：在“使用向导”创建企业并将自己设为初始企业管理员，或在平台管理中指定其他用户。切换到企业后，以企业管理员继续。

在“使用向导”中点击“导入离线演示”，显式创建虚构 SaaS「青禾协作」的知识库、文档和离线演示 Agent。重复导入使用已有演示资源，不覆盖用户内容；查看返回的文档状态，未就绪时到知识库检查或重新处理。此操作不调用外部模型，也不创建会话、公开入口或运营统计。

初次写入中断后，再次显式导入可恢复同一文档的原始演示内容；删除文档、停用 Agent 或撤销知识库授权后，导入会拒绝覆盖或恢复授权。若管理员已将整个演示组合全部移除，下一次显式导入按新组合处理，不维护额外的永久删除标记。

1. 在“客服会话”选择离线演示 Agent，尝试询问试用期、支持时间或 CSV 导出方式。
2. 在已有会话中体验人工接管与协作；运营概览只展示实际产生的数据。
3. 在“公开客服入口”手动发布需要的 Agent，再复制公开链接或嵌入代码。访客会话需要配置 `PUBLIC_RATE_KEY`。
4. 替换演示资料时，在知识库和 Agent 页面自行管理资料、授权和发布；外部模型需要部署方明确启用、配置凭证和预算。

演示验证操作流程，不代表真实模型回答质量或生产验收。网站接入见[网站集成](WEBSITE_INTEGRATION.md)，配置和权限问题见[部署与恢复](DEPLOYMENT.md)及[运维与安全](OPERATIONS.md)。

## P13 本机验证边界（2026-10-31）

- 仅新建且获授权的 `support_agent_p13_check` 执行既有 0001–0010 迁移；无新增 schema、依赖或测试框架，自动化测试仍为 Python 0 / JavaScript 0。
- 一次性 CLI/HTTP 操作：全新私有配置、重复配置字节不变、管理员初始化、只读 setup、带引用的离线问答、人工接管、发布与访客问答、实际运营统计、公开撤销均通过。访客请求使用独立的 `Visitor` 认证，不能使用管理端 Bearer 方案。
- 匿名 401、普通成员和伪造企业 403、跨企业资源 404；撤销授权后重复导入拒绝，未恢复授权。伪造 Host 未改变服务端提供的 WEB_ORIGIN。
- 两次定向原子检查：小写环境变量中的生产模式在写文件前被拒绝；模拟首次写入中断留下 pending 记录后，显式导入恢复同一文档为 ready。一次性验证代码未保留为测试套件。
- 既有静态检查 1.011 秒通过（80 个 Python AST 文件、10 个迁移）；交付检查 0.845 秒通过（JavaScript 语法/模块、HTML DOM、17 个资源、链接和敏感文件扫描）。当前会话无 uv，使用现有虚拟环境及本机缓存的 Hatchling 构建 wheel，核对打包资源与源码一致。
- NOT_RUN：全新 macOS 主机安装与 INIT 分支、uv 安装/同步、浏览器 GUI/剪贴板/真实站点嵌入、Linux、Docker、真实模型、生产部署、生产负载、共享存储及多实例。P12 其他生产验收缺口继续有效；未查询 GitHub Actions。
