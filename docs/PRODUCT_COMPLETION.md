# P5 产品化设计与实施范围

以本地未提交 P4 为基线，增量完善可自部署、可配置、可发布的通用客服产品。没有行业适配、真实模型调用、提交、推送或生产部署。

- 保留已开始的原生 ES Modules 管理前端，随 FastAPI 同源提供，无 Node 运行/构建依赖。后台负责登录、企业切换、统计、配置、知识库、工具授权、会话与审计；不重复引入第二套 Vue 前端。
- Cookie 认证沿用已有哈希管理会话，HttpOnly、SameSite Strict、写请求精确 Origin；保留 Bearer API。企业切换丢弃旧请求结果。管理页面禁止 iframe。
- Agent–知识库授权通过 0007 的 FORCE RLS 关联表、复合企业外键和版本控制完成。统一 Agent 轮次复用 P2 检索/逐字引用验证和 P3 工具循环。人工处理状态暂停 AI；原 API 不能绕过角色限制恢复 AI。
- 0008 增加公开定位、发布配置和访客会话。只有最小随机入口→企业映射表是全局定位；配置和会话表 FORCE RLS。访客 Token 与管理认证分离、仅哈希存储、12 小时有效、绑定入口/版本/会话。结束、撤销、下线、配置变化或身份撤权后安全拒绝。
- 发布固定 Agent 版本，公开只读工具需额外显式白名单。每个 I/O 后重新验证；交付短事务按发布→发布者/企业/成员→会话→配置→工具/知识资源的顺序保护相应权限。模型和工具网络/进程执行前提交，不跨 I/O 持锁。内部记账可在撤权后完成，不允许借此交付内容。
- 匿名创建与模型调用采用 PostgreSQL 锁和持久计数；IP 使用独立 PUBLIC_RATE_KEY 的按入口 HMAC。保留企业/Agent 预算，访客独立限额，不消耗发布者个人额度。反向代理负责通用 HTTP/连接限流。
- 提供独立响应式访客页面和轻量 iframe 小组件。只用安全 DOM/textContent 渲染；来源和工具结果是数据，不解释 HTML。受限浏览器存储时退回当前页面内存，刷新可能需要重新开始。
- 外部模型默认关闭；离线演示明确标识。真实 Provider 能力通过 Mock 与本地 HTTP 服务验证，不伪造实际模型效果。数据库/文件/主密钥备份关系、Linux 部署与恢复窗口有文档；主密钥轮换仅保留恢复方案。

执行：需求/源码核对 → 权限边界定向验证 → 用户授权增量迁移 → 后台及公开交付 → 关键回归/HTTP/打包 → 运维文档。实际证据与未验证项统一见 [验收记录](ACCEPTANCE.md)。
