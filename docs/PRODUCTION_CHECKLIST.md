# 生产上线检查清单

这是待部署方填写的清单，不代表本项目已在生产环境验收。状态区分：**已实现**指仓库具备能力；**静态核对**指需要检查配置或代码；**未执行**指仍需在目标环境实际验证。预检结果不能替代下列验收；不要记录密钥或包含敏感信息的连接串。

| 项目 | 当前状态与上线前动作 |
| --- | --- |
| 生产网络 | 静态核对：按 [部署文档](DEPLOYMENT.md) 配置 HTTPS、准确的 WEB_ORIGIN、私网数据库、回环后端和受信代理；替换 [Nginx 示例](../deploy/nginx.conf.example) 的域名和证书。未执行：在目标环境检查 TLS、转发头伪造、Origin 和各路径。 |
| 数据库权限与迁移 | 已实现显式迁移和租户 FORCE RLS；静态核对迁移角色、运行角色及授权；设置 `DEPLOYMENT_ENVIRONMENT=production` 并运行只读 `uv run python -m support_agent.cli preflight --production`，error 退出码 1，生产启动也强制严格预检。HTTP 进程不得配置迁移连接。未执行：在获授权的目标数据库上检查迁移版本和实际租户隔离。 |
| 入口与容量 | 已实现可选 PostgreSQL 共享入口限制，默认关闭；静态核对入口保护、密钥和阈值，并配置代理限流；默认单实例，多实例须共享数据库和同一私有文档文件系统及权限，先验证后使用。未执行：负载、并发、SSE、上传和故障时拒绝准入验证。 |
| 数据与恢复 | 静态核对数据库、文档、对应密钥的备份和访问控制；未执行：在新建隔离目标完成恢复演练，验证数据、文档、凭证解密及撤销/删除重放。 |
| 密钥与保留 | 已实现租户级主密钥维护流程和显式保留 CLI；静态核对旧密钥、轮换窗口、保留期限和审批。未执行：针对目标环境演练轮换恢复及有界清理。 |
| 外部服务 | 默认关闭外部模型；未执行：批准供应商、模型、预算和精确主机后验证真实连接、质量、费用和故障行为。 |
| 运维可观测性 | 已实现健康接口和安全日志；仅 live 豁免入口限流，ready/setup 计数，setup 只返回匿名简要状态；日志耗时不代表完整 SSE 交付。未执行：配置外部日志采集、告警、监控、保留和响应责任人，并验证告警。 |

预检仅报告其实际检查的配置与数据库状态；检查通过、容器健康或离线验收均不是生产上线证明。操作细节见 [运维文档](OPERATIONS.md) 和 [P7 运行维护](P7_RUNTIME.md)。
