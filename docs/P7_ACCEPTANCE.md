### 架构与审查

版本 0.6.0，新增两个 SSE API；数据库 head 仍为 `0008_public_delivery`，**无 P7 schema 迁移、无新增依赖**。密钥版本复用已有密文字段封装，保留策略复用原数据及审计表。原租户 RLS、成员认证、公开固定版本、访客额度、幂等和 Provider/工具边界保留。更改按完整调用链静态复核，未使用额外 subagent/GUI。

SSE 不把模型输出视作授权，模型和工具仍经原执行引擎；每段前刷新身份、配置/凭证、来源和工具交付检查。客户端中断不会取消有界任务或触发自动重发；数据库事务在事件网络等待前关闭。维护命令是持有运行 DB 凭证的本机运维能力，不提供公开 HTTP 入口，所有选择显式企业范围并保持 FORCE RLS；成功审计与数据修改同事务。

关键新增路径：evaluation.py、retrieval.py/search_text.py、streaming.py/stream_events.py、credentials.py/maintenance.py/retention.py、cli.py、web/stream.js、.github/workflows/ci.yml。操作步骤见 [质量评测](P7_QUALITY.md) 和 [运行维护](P7_RUNTIME.md)。P6 验收文档原样保留。

### 未验证与暂缓

- NOT_RUN：真实模型/供应商联调、真实语义正确率、一般提示注入对抗、GUI 实际体验、生产 HTTPS/容量/运维切换。没有真实 Key、模型费用或远程部署。
- DEFERRED：pgvector、Embedding、reranker（缺扩展或独立收益证据），上游原生 token streaming，无停机密钥热分发、全链路隐私擦除。
- 轮换需要维护窗口及全部旧密钥，单企业最多 1000 凭证；清理每类最多 100 根记录/总计最多 10000 影响行，超过时拒绝执行，不能假装已完成大规模维护验收。
- 网络已发送字节不可撤回，断连后的客户端须查询记录；SSE 不构成服务端与客户端之间的分布式原子交付。
