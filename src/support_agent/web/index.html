知应SUPPORT AGENT

让回答有依据，
让服务有记录。

独立的企业客服工作台。管理知识、配置助手，在同一处查看对话与执行记录。

离线演示与真实模型明确区分。未配置模型时，也可以管理知识和验证平台流程。

登录工作台

使用平台管理员分配的账号。

首次使用

在项目目录运行 uv run python -m support_agent.cli setup 检查配置并获取恢复指引。全新安装可加 --configure 交互配置； 数据库就绪后由部署管理员运行 create-admin 创建首个账号。 没有默认账号或密码；登录后打开“使用向导”。
