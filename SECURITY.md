# Security policy

Report suspected vulnerabilities privately through [GitHub security advisories](https://github.com/koajsj/kefuagent/security/advisories/new), if private reporting is enabled. Do not include credentials, personal data, or exploitation details in public issues. If private reporting is unavailable, contact a maintainer privately before sharing details; availability and response times are not guaranteed.

At the 2026-11-07 review, private vulnerability reporting was disabled. Until a private channel is enabled, an issue may request a confidential contact method only; do not post the vulnerability itself. Share affected versions, impact and a minimal reproduction privately, coordinate a fix and disclosure date, then publish a sanitized advisory after the fix. No response SLA is promised.

The current development version is 0.7.1. Security fixes are evaluated against the current code; no support lifetime for older versions is promised. See [deployment guidance](docs/DEPLOYMENT.md) for operational security and backup requirements.
